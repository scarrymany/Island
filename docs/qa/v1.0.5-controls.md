# Карта проверок SCARP ISLAND 1.0.5

## Границы проверки

`test_settings_workflows` создаёт отдельные `SettingsWindow` и `ConfigStore` для каждого сценария. Все JSON-файлы, профили, темы, перезаписи и удаления находятся в `QTemporaryDir`. В тестах нет `Application`, настоящего медиаплеера, изменения громкости Windows, регистрации горячих клавиш или автозапуска. Вызов ссылки GitHub перехватывает `QDesktopServices::setUrlHandler`; браузер не открывается. Для автоматизации диалогов используется `Qt::AA_DontUseNativeDialogs`.

Основные автоматические сценарии дополняют `settings`, `settings_controls`, `config`, `hud`, `platform` и `session_volume`. Они проверяют путь от элемента управления до сохранённого JSON и обратного обновления окна.

## Визуальная матрица

Автоматический сценарий открывает все семь страниц при размерах 820x520, 1080x800 и 1400x950; шрифтах 8, 10 и 18; тёмной и светлой палитрах. Проверяет доступность viewport, отсутствие горизонтального обрезания содержимого, достижимость конца прокрутки и получение изображения. Это не оценка качества изображения человеком.

Локальный стенд `.scratch/settings-acceptance-105` создаёт фиктивный HUD, проигрыватель, громкость и результат обновления. Режим `--capture-dir ... --full-matrix` сохраняет 252 снимка: верх/низ каждой страницы для всех сочетаний. `geometry.json` содержит размеры viewport, содержимого, карточек и диапазон прокрутки. Режим `--popup-dir ...` снимает открытие, раскрытое состояние и закрытие шести типов списков; отдельный `*-popup.png` содержит меню целиком. Файлы стенда и снимки исключены из Git.

## Что требует отдельного подтверждения

| Область | Почему не подтверждается только workflow-тестами |
| --- | --- |
| Native Windows popup, DWM, системный drag/resize, несколько физических мониторов и DPI | Требуется интерактивный Windows desktop; offscreen не является доказательством работы оконного менеджера |
| Цвет, файловый диалог и ввод имени в Windows | Workflow проверяет те же обработчики с Qt-диалогами; внешний вид системного диалога требует ручного осмотра |
| Настоящий проигрыватель и системный микшер | Стенд имитирует медиасессию, чтобы не менять пользовательский звук; отдельные `media`/`session_volume` проверяют соответствующие компоненты |
| Реестр автозапуска и глобальная горячая клавиша | Проверены запись конфигурации и существующие platform-тесты; workflow не меняет состояние ОС |
| Действительная загрузка и запуск нового установщика | `platform` использует подставной сетевой ответ; установка требует отдельной проверки релизного пакета |
| Субъективная читаемость, контраст и отсутствие обрезания в каждом снимке | Наличие файла не равно визуальному одобрению; результаты осмотра должны быть указаны отдельно |

## Результат выполнения

Финальная проверка 28 сентября 2026 года, Windows 11, MSVC x64, Qt 6.8.3:

| Проверка | Результат |
| --- | --- |
| Финальная Release-сборка и CTest | 12/12 наборов прошли, 0 failed; 28,53 сек |
| `test_settings`, native Windows backend | 11 passed, 0 failed, 0 skipped |
| `test_settings_workflows`, native Windows backend | 15 passed, 0 failed, 0 skipped |
| Визуальная матрица всех страниц | 252 кадра; 0 случаев горизонтального обрезания по геометрии; 0 полностью пустых концов прокрутки |
| Выпадающие списки | 6 полных изображений меню и 30 кадров стадий открытия/закрытия; source, layout, HUD font, font weight, settings font, hide delay |
| Пользовательский `Island/config.json` | SHA256 до и после проверки совпадает |

В ходе проверки обнаружены и закрыты дефекты:

- Ряды кнопок обрезались при шрифте 18 и окне 820x520. До исправления страница «Профили» имела ширину 616 px при viewport 530 px. Адаптивные ряды теперь переносят кнопки по вертикали.
- Длинный или многострочный статус увеличивал нижнюю панель. Статус занимает одну строку, полное сообщение доступно в tooltip.
- Повторное применение стилей после изменения размера шрифта заменяло Inter на Segoe UI в Windows backend. Семейство шрифта сохраняется.
- Страницы «Внешний вид» и «Система» прокручивались в пустую область ниже последней карточки. Верхнее выравнивание теперь обеспечивается растяжкой в конце layout; фактическая высота карточек соответствует диапазону прокрутки.
- Переключатели эффектов при шрифте 18 и окне 820x520 сжимались до 33 px при необходимой ширине 48 px; обрезались дорожка и ползунок. Явная минимальная ширина сохраняет весь переключатель. Строгая проверка всех переключателей добавлена в матрицу, отдельный нативный снимок подтверждает исправление.

Регрессионные тесты воспроизвели ошибки до исправления и прошли после него. Просмотрены контактные листы семи страниц, крайние сочетания размера окна/шрифта, обычный список, список шрифтов и интервалы скрытия. Локальные артефакты: `build/settings-captures-105-release`, `build/settings-popups-105-final`, `build/settings-toggles-105-final`, `build/settings-native-release-105.txt`, `build/settings_workflows-native-release-105.txt`. После последней правки минимальной ширины переключателей повторный полный workflow-прогон дал 15 passed, 0 failed в обоих backend; дополнительно переснят изменённый участок страницы анимаций.

Независимое ревью `scripts/test-installer.ps1`, `scripts/release.ps1` и защиты временной конфигурации в `main.cpp` не обнаружило блокирующих замечаний; PowerShell Parser сообщил 0 ошибок. Финальный развёрнутый пакет 1.0.5 запущен с PATH, содержащим только системные каталоги Windows: завершение с кодом 0, диагностических ошибок нет, пользовательская конфигурация не изменилась.

Релизный workflow дополнительно проверяет настоящую установку и удаление на чистом Windows runner: версию, регистрацию только для текущего пользователя, ярлык, запуск без Qt SDK и отсутствие остаточных файлов. Публикация пакетов зависит от успешного завершения этих проверок. Результаты доступны в [Windows build and release](https://github.com/scarrymany/Island/actions/workflows/build.yml).
