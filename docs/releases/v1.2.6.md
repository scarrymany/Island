# SCARP ISLAND 1.2.6 - SCARPIFY на островке

## Поддержка SCARPIFY

- Островок показывает трек из [SCARPIFY](https://github.com/scarrymany/scarpify): название, исполнителя, обложку и прогресс. В списке источников он подписан как SCARPIFY
- Воспроизведение, пауза, переключение треков и перемотка с островка управляют плеером SCARPIFY
- Ползунок громкости меняет громкость SCARPIFY в микшере Windows, в том числе когда SCARPIFY запущен с ярлыка: такие сессии Windows подписывает идентификатором приложения, а не именем файла
- Нужен SCARPIFY 0.2.4 или новее: начиная с этой версии он публикует системную медиасессию Windows, из которой островок берёт музыку
