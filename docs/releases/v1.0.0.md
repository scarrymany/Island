# Island 1.0.0

Первый выпуск музыкального островка для Windows на C++20 и Qt 6.

![Island](https://raw.githubusercontent.com/scarrymany/Island/v1.0.0/docs/screenshots/hud.png)

### Что умеет

- Получает музыку из Windows Media Session: Spotify, SoundCloud в поддерживающих браузерах и другие плееры.
- Показывает обложку, трек, исполнителя, альбом, источник и прогресс. Управляет воспроизведением, перемоткой и системной громкостью.
- Позволяет менять оформление, размеры и положение каждого элемента. Есть темы, профили, импорт и экспорт.
- Работает с несколькими мониторами, глобальной горячей клавишей, автоскрытием и автозапуском.
- Закрывает настройки в трей. Повторный запуск открывает существующий экземпляр.
- Проверяет новые релизы и SHA-256 установщика перед обновлением по кнопке.

### Скачать

- **Island-Setup.exe** - установка для текущего пользователя.
- **Island-win-x64.zip** - переносимая версия; распакуйте папку целиком и запустите `Island.exe`.
- **SHA256SUMS** - контрольные суммы.

Windows 10 1809+ или Windows 11, x64. Python, .NET и Qt SDK не нужны.

По умолчанию `Ctrl+Alt+M` показывает и скрывает островок. Настройки открываются через значок трея; «Выход» завершает приложение.

Сведения о музыке и доступные кнопки зависят от источника. Поверх игр поддерживаются оконный и безрамочный режимы; эксклюзивный полноэкранный режим может перекрывать HUD.
