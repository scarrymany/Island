# SCARP ISLAND 1.2.2 — точные мелочи

## Перетаскивание без рывка в конце

- После отпускания островка его окно меняет рамку. Раньше Windows могла на один кадр показать старую картинку на новом месте, и текст дёргался. Теперь рамка меняется сразу после вертикальной развёртки и тут же перерисовывается, поэтому композитор получает уже готовый кадр

## Меню без прыжков выделения

- Подсветка пункта следует за курсором мгновенно и больше не «едет» за ним, задерживаясь на пунктах, с которых курсор уже ушёл
- Меню появляется плавным проявлением на месте, без сдвига под курсором

## Без лишних подсказок

- При наведении на островок больше не всплывает «Перетащите островок. Правая кнопка - меню». Подсказки остались только у кнопок, прогресса и громкости
