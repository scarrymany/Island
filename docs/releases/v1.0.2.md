# SCARP ISLAND 1.0.2

Приложение теперь называется SCARP ISLAND. Настройки переработаны в стиле SCARP: графитовые поверхности, белые акценты, встроенный Inter и единая иконка окна, трея и установщика.

- Добавлены плавное появление страниц и анимированные переключатели. Частота следует монитору окна настроек; эффекты и длительность настраиваются отдельно от HUD.
- Размеры, прозрачность и длительности меняются ползунками. Рядом остаётся точный ввод без стандартных стрелок.
- Таймер полного скрытия предлагает готовые интервалы, «Не скрывать» и свой интервал. Поле сочетания клавиш получило кнопку восстановления Ctrl+Alt+M.
- Убрана пунктирная системная рамка кнопок. Управление с клавиатуры сохраняет собственную подсветку фокуса.
- Громкость HUD управляет звуковыми сессиями текущего приложения в микшере Windows. Для сайтов меняется громкость всего браузера. Общая громкость устройства не меняется; неопределённый источник не получает управление чужим звуком.

Настройки, профили, адрес обновлений и имена файлов сохранены для совместимости. Собственные цвета интерфейса продолжают применяться.

**Island-Setup.exe** - установщик SCARP ISLAND. **Island-win-x64.zip** - переносимая версия. **SHA256SUMS** - контрольные суммы.

[Инструкция и скриншоты](https://github.com/scarrymany/Island#readme)
