# SCARP ISLAND 1.1.1 — шрифты и плавность

В обновлении добавлено 55 шрифтов с русской и украинской кириллицей: всего доступно 61 встроенное семейство. Шрифты работают в переносимой версии без установки в Windows; их лицензии SIL OFL 1.1 включены в пакеты.

При быстром переключении страниц настроек затухание продолжается с текущего значения без скачка яркости. HUD останавливает таймер перерисовки при воспроизведении, когда время скрыто и индикатор прогресса не может отображаться. Очень большие значения длительности медиазаписей теперь безопасно ограничиваются перед форматированием.

Формат конфигурации и сохранённые профили не изменены. Для Windows 10 1809 и новее доступны установщик `Island-Setup.exe` и переносимый архив `Island-win-x64.zip`; контрольные суммы публикуются в `SHA256SUMS`.
