# SCARP ISLAND 1.2.4 - плавные настройки

## Анимации с частотой монитора

- Прокрутка, слайдеры, всплывающие меню, диалоги и подсказки работали на 60 кадрах в секунду даже на мониторах 144-240 Гц. Кадры держались на экране неравное время, и движение дёргалось. Теперь каждая анимация берёт частоту экрана, на котором открыто окно
- Положение в каждом кадре считается по развёртке экрана, а не по моменту срабатывания таймера Windows. Поэтому шаги движения ровные, даже если таймер просыпается с опозданием

## Прокрутка без рывков

- Каждый щелчок колеса раньше запускал кривую заново, и при быстрой прокрутке скорость скакала. Теперь страница сдвигается в первом же кадре и плавно тормозит, а следующие щелчки только продлевают это движение
- Индикатор выбранного раздела в боковом меню сохраняет скорость, если быстро переключать разделы подряд

## Спокойная смена разделов

- Старая страница коротко гаснет, новая поднимается на место. Страницы больше не просвечивают друг через друга, а текст во время перехода не размывается

## Новый шрифт настроек

- Окно настроек, меню и диалоги набраны системным шрифтом Windows 11 Segoe UI Variable. Он чётче на масштабе 100%, где Inter выглядел размытым. В Windows 10 используется Segoe UI
- Обычный текст набран нормальным начертанием, заголовки - полужирным, так что иерархия читается сразу. Раньше почти всё было полужирным
- Если в настройках остался прежний шрифт по умолчанию (Inter), он один раз заменится на новый. Выбранный вручную шрифт сохраняется, а вернуть Inter можно в разделе «Система»
