# SCARP ISLAND 1.2.3 - свободный край экрана

## Клики под полоской снова работают

- Раньше достаточно было задеть свёрнутую полоску курсором и увести его, не раскрывая островок: под полоской оставалась невидимая область размером с раскрытый островок, и она перехватывала клики по вкладкам, заголовкам окон и ярлыкам. Теперь после короткой анимации отклика кликабельной остаётся только сама полоска
- Пока полоска откликается на курсор, захватывается лишь узкая кайма вокруг неё, а не вся область под ней
