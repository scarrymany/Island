# SCARP ISLAND 1.0.5

Доработаны настройки, выпадающие списки и обновления.

- Все списки получили общее оформление со скруглениями, плавным появлением и закрытием. Меню сохраняет ширину поля, помещается на экране и открывается вверх, если снизу мало места.
- Список шрифтов использует ровную типографику без системных значков и разномастных образцов. Текущий шрифт виден при открытии, длинные списки прокручиваются.
- Изменение размера текста больше не сбрасывает выбранное семейство шрифта на системное.
- Исправлена обводка, остававшаяся после кликов. Управление с клавиатуры сохраняет заметный фокус, выбор стрелками и Enter, отмену через Esc.
- Поле горячей клавиши получило внутренние отступы. Кнопка «Вернуть» по-прежнему восстанавливает Ctrl+Alt+M.
- На узком окне с крупным шрифтом кнопки перестраиваются в столбец, содержимое страниц больше не обрезается справа. Длинный статус не увеличивает нижнюю панель; полный текст доступен в подсказке.
- Исправлена высота длинных страниц при крупном шрифте: карточки не сжимаются, в конце прокрутки не остаётся пустой экран.
- Переключатели больше не обрезаются на узком окне с крупным шрифтом.
- Вместо редактирования адреса обновлений добавлена кнопка с иконкой GitHub. Она открывает публичную страницу SCARP ISLAND. Обновления всегда проверяются в официальном репозитории.
- Если отключить проверку обновлений сразу после запуска, отложенный запрос больше не выполняется. Ошибки HTTP отображаются понятнее, проверка адреса установщика стала строже.
- Открытый список корректно закрывается при исчезновении источника данных, смене раздела и скрытии окна. Быстрое переключение между списками не оставляет прежнее меню поверх нового.

Настройки и профили предыдущих версий сохраняются. Анимации панели учитывают частоту её монитора; длительность и отключение эффектов доступны в настройках.
